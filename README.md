# 電工工作紀錄 / Electrician Work Record

各單位填寫電工來訪維修紀錄的 Google Apps Script 網頁表單，資料自動存入 Google 試算表。

---

## 功能

- 中越文雙語介面
- 設備名稱支援清單過濾或自由輸入
- 區域欄位支援 280 筆清單過濾輸入
- 報修時間與完成時間各自帶日期，支援跨日記錄
- 手機與電腦均可使用（RWD 響應式排版）
- 送出後資料自動寫入試算表，標題列自動建立

---

## 試算表分頁設定

部署前請先在試算表建立以下兩個分頁：

### 人員設定
| A 欄（部門） | B 欄（電工姓名） | C 欄（設備清單） |
|------------|----------------|----------------|
| 織造一課 | 王大明 | 變頻器 |
| 染整 | 李小華 | 馬達 |
| … | … | … |

> 三欄長度不需相同，有幾筆填幾筆。

### 區域清單
每欄一個區域，往下列號碼：

| A（01區） | B（02區） | … |
|-----------|-----------|---|
| 01-01 | 02-01 | … |
| 01-02 | 02-02 | … |

可用以下公式自動產生（貼在 A1）：
```
=ARRAYFORMULA(TEXT(INT((SEQUENCE(50)-1)/10)+1,"00")&"-"&TEXT(MOD(SEQUENCE(50)-1,10)+1,"00"))
```

`電工工作紀錄` 分頁會在第一筆資料送出時自動建立。

---

## 部署步驟

1. 開啟 Google 試算表 → **擴充功能** → **Apps Script**
2. 將 `Code.gs` 內容貼入預設的 `Code.gs`
3. 點左側「**+**」→ 選「**HTML**」→ 命名為 `index`（不含副檔名）→ 貼入 `index.html` 內容
4. 儲存全部檔案
5. 點右上角「**部署**」→「**新增部署**」
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 存取權限：**所有人**
6. 複製部署網址，發給各單位

---

## 表單欄位

| 欄位 | 必填 | 說明 |
|------|:----:|------|
| 部門 | ✓ | 下拉選單，來源：人員設定 A 欄 |
| 填表人 | ✓ | 自由輸入 |
| 設備名稱 | ✓ | 可選清單或直接輸入，來源：人員設定 C 欄 |
| 區域 | — | 輸入過濾，來源：區域清單分頁 |
| 設備號碼 | ✓ | 自由輸入 |
| 報修日期時間 | ✓ | 含日期，預設為現在 |
| 維修人員 | ✓ | 下拉選單，來源：人員設定 B 欄 |
| 工作類型 | ✓ | 保養 / 故障修復 / 新裝 |
| 完成日期時間 | — | 含日期，跨日亦可 |
| 結果 | ✓ | 完成 / 待處理 |
| 備註說明 | — | 請說明具體工作內容，例：更換3號機台送風變頻器 |
